# 검증 및 인수 체크리스트

## 자동 검증 (2026-09-07)

- `npm test`: 8개 통과. 임시 SQLite, localhost HTTP, 모의 브라우저 스크립트 실행만 사용.
- `python -m unittest -v test_worker.py`: 4개 통과. 모의 HOMS 어댑터 사용, Chrome 미실행.
- EJS 렌더 후 인라인 JavaScript 문법 검사 통과; 별도 admin/request-client JavaScript 문법 검사 통과.
- Python 모듈 컴파일 검사 통과.
- DB 무결성과 재시작·백업 복원본 읽기 검증.

## 확인한 사고 시나리오

| 상황 | 검증 결과 |
|---|---|
| 접수 응답 유실 후 다시 누름 | 같은 요청번호·같은 본문으로 재확인, 수량이 바뀌어도 이전 요청 보존 |
| 동일 요청번호로 다른 데이터 | 서버 거부 |
| 잘못된 자재·수량·매니저 | 저장 전 거부 |
| 두 처리기가 같은 큐 점유 | 진행 중 항목이 있으면 추가 점유 차단 |
| begin 응답 유실 | HOMS 불출 클릭 0회 |
| complete 응답 유실 | 재불출 클릭 차단, 확인 필요로 중단 |
| 일부 항목만 완료 | 완료 항목 재배정 없음 |
| 서버 재시작/전체 정지 | 진행 중 항목 확인 필요, 전체 정지 상태 |
| 담당자/자재 선택자 미검증 | 실제 모드 시작 차단 |

## 아직 검증하지 않은 것 — 운영 전 필수

- Render 영구 디스크 연결/환경변수/새 버전 배포.
- 회사 PC의 Chrome/Selenium 드라이버 설치 및 회사 네트워크 정책.
- HOMS 실제 DOM 선택자, 담당자 고유 ID, 자재코드, 수량 단위.
- 실제 HOMS 로그인·불출·완료 내역 조회 (이 작업에서는 실행하지 않음).
- 실제 운영 DB의 GitHub 백업 인증 및 업로드. 비공개 저장소에 올린 것은 빈 구조 확인용 DB뿐.
- 화면 크기별 실제 브라우저 시각 테스트.
